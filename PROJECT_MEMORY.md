# Archive of our Books (Ao²B) — Project Memory

## Project Overview
Archive of our Books (Ao²B) is a premium, book-focused social media platform designed for high-fidelity book tracking and visual reviews.

---

## 🎨 Branding & Terminology
- **Global Logo**: $Ao^2B$ (AO3-inspired, left-aligned, serif high-contrast). The superscript 2 represents "of our".
- **Terminology**: Content published by users is called a "Post" (formerly known as 'Photo Post').

---

## 🛠 Tech Stack
- **Framework**: Next.js 16.2 (App Router)
- **Styling**: Vanilla CSS + Tailwind Utility Classes
- **Rich Text**: TipTap Editor
- **Icons**: Lucide React
- **Charts**: Chart.js (Radar Charts for book aesthetics)
- **Backend/Auth**: Supabase (PostgreSQL + Auth)
- **APIs**: 
  - Google Books API (Search & Metadata)
  - NYT Books API (Trending Lists)

---

## ✨ Key Features (Frontend Phase)
- **Unified Post Creator**: Support for visual posts and "Deep Reviews" with aesthetic rating sliders.
- **Smart Book Covers**: Cascading fallback logic (Zoom 3 → 2 → 1) to ensure high-resolution covers from Google API.
- **Rich Text Editing**: Captions with bold, italic, underline, and emoji support.
- **Dynamic Profile**: Instagram-inspired grid with hover stats and aggregate reading mood charts.
- **Library Management**: Status tracking (TBR, Reading, Finished) with reading progress markers.

## 🔑 Key Architectural Decisions

### `author: string` (not `authors: string[]`)
- **Resolved 2026-06-06**: `LibraryItem` interface in `ReviewContext.tsx` uses `author: string` to exactly match the Supabase `library.author (text)` column.
- All components (`library/page.tsx`, `profile/page.tsx`, `browse/page.tsx`, `post/review/page.tsx`, `CurrentlyReading.tsx`, `SettingsModal.tsx`) have been updated to use `item.author` directly (no `.join()`).

### `book_id` vs `id` in Library
- Supabase `library.id` is an auto-increment `int8` (generated by DB).
- Our local `LibraryItem.id` stores the **Google Books volume ID** (string like `"B1hSG45JCX4C"`).
- Supabase deletes use `.eq('book_id', id).eq('user_id', ...)` — never `.eq('id', ...)`.

### Add Book Search Engine (Browse Page)
- Search via Google Books API: `https://www.googleapis.com/books/v1/volumes?q=...`
- `+ Add to TBR` button on each card fires Supabase insert + optimistic context update.
- No `alert()` popups — all errors go to `console.error("Supabase Insert Error:", err)`.
- Button shows `"..."` during insert, `"✓ Added"` (emerald) on success, rolls back if insert fails.

### Remove from Library
- Trash icon appears in hover overlay on every book card in `library/page.tsx`.
- **Optimistic**: `removeFromLibrary(id)` fires immediately → book disappears from UI.
- **DB delete**: `.delete().eq('book_id', id).eq('user_id', session.user.id)` fires async.
- Errors logged to `console.error("Supabase Delete Error:", ...)` only.
